# Student Management System

A C# console application developed as my Phase 1 C# project.

## Features

- Add students with input validation
- Display all students
- Search students by ID
- Update student information
- Remove students
- Display passed and failed students
- Calculate grade statistics
- Sort students by grade
- Manage student status using an enum
- Use LINQ for searching, filtering, sorting, and statistics

## Technologies

- C#
- .NET
- LINQ
- Git & GitHub

## Concepts Practiced

- Classes and objects
- Properties and constructors
- Lists
- Methods
- Input validation
- Enums
- LINQ
